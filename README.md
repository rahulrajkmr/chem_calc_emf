# Galvanic Cell EMF Calculator

Beginner Python website. It calculates standard cell EMF and the Nernst equation.

## Run locally

```bash
python3 run.py
```

Open http://localhost:8000

Do not open `index.html` as a file. The browser needs a local server so it can load `calculator.py`.

## GitHub Pages

Push to `main` or `master`, then set **Settings → Pages → Source → GitHub Actions**.
